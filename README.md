🏠 Sistema de Gestão de Aluguel

📋 Sobre o projeto

Sistema web desenvolvido para auxiliar na gestão de imóveis para aluguel, centralizando informações e facilitando o controle de propriedades, locatários e contratos.

O projeto faz parte do meu portfólio na área de Análise e Desenvolvimento de Sistemas, utilizando tecnologias web e Inteligência Artificial como apoio durante o processo de desenvolvimento.

Desenvolver uma solução web simples e intuitiva para organizar e facilitar o gerenciamento de imóveis alugados, aplicando conhecimentos de desenvolvimento web e utilização de Inteligência Artificial no processo de criação.
